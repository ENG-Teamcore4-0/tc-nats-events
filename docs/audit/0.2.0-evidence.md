# Evidence: audit fixes in tc-nats-events 0.2.0

- **Audit:** 2026-09-30, commit `f343738` (v0.1.7)
- **Fix branch:** `fix/audit-0.2.0`
- **Environment:** nats-server 2.10.29 (`nats:2.10-alpine -js`), nats-py 2.16.0, Python 3.12

## Method

1. First, the tests in `tests/audit/` were written against the **public API of 0.1.7**. `make_config()` drops config fields that `main` does not know.
2. The same suite was run in a worktree of `f343738` → [`red-main-f343738.txt`](red-main-f343738.txt), with **26 failures**.
3. The same suite was run on the fix branch → [`green-fix-audit-0.2.0.txt`](green-fix-audit-0.2.0.txt), with **35/35 passing**.
4. Full suite: `pytest tests` gives **332 passed, 84% coverage**. That covers unit, integration, audit and the 3-node cluster.

Reproduce with:

```bash
docker run -d -p 4222:4222 nats:2.10-alpine -js
make test-audit            # GREEN on the branch
make test-cluster          # R3 on 3 nodes (NATS-05)
```

To reproduce RED: `git worktree add /tmp/m f343738 && cp -r tests/audit /tmp/m/tests/`, then run pytest with `PYTHONPATH=/tmp/m/src`.
